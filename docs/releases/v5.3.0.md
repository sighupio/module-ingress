# Ingress Module Release v5.3.0

Welcome to the latest release of `Ingress` module of [`SIGHUP Distribution`](https://github.com/sighupio/distribution) maintained by team SIGHUP.

This release updates the Ingress NGINX controller image to `v1.15.16-chainguard`, which fixes the nginx2root CVEs: CVE-2026-123007, CVE-2026-123634, CVE-2026-123633, CVE-2026-121810 and CVE-2026-113425.
